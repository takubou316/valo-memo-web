# valo-memo 作戦ボード（ブラウザ版）

VALORANT の作戦ボード（マップにキャラ・スキル・矢印などを置いて作戦を描く）を、ブラウザで使えるようにしたものです。
PC用アプリ「valo-memo」の作戦ボードと同じもので、友達と**一緒に作る**（同時に操作する）ための招待URLの受け口になっています。

- 開く: https://takubou316.github.io/valo-memo-web/
- 招待URL（`#room=...&k=...` 付き）で開くと、「アプリで開く」か「ブラウザで参加」を選べます

## データの扱い
- 作戦と貼った画像は、**このブラウザの中（IndexedDB）にだけ**保存されます。サーバーには保存しません
- 一緒に作るときは、WebRTC で参加者のPC同士が直接つながってやりとりします（ライブラリ: [Trystero](https://github.com/dmotz/trystero)）
  - 最初の顔合わせだけ、公開の Nostr リレーを使います。リレーに届くのは、ハッシュにした部屋の名前と、合言葉で暗号化した接続情報だけです
  - 招待URLの `#` より後ろ（部屋の名前と合言葉）は、このページのサーバー（GitHub Pages）にも送られません
  - **招待URLを知っている人は誰でも作戦を編集できます**。知らない人には送らないでください
- マップ・キャラの情報と画像は、非公式の [valorant-api.com](https://valorant-api.com) から読み込みます

## このリポジトリについて
アプリ本体（非公開リポジトリ）の作戦ボードの画面から、`tools/build-web.js` で組み立てたものです。ここを直接編集せず、アプリ側を直して組み立て直します。
